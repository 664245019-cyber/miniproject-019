## 1. การกำหนดปัญหาและ Dataset
- **ปัญหา:** โรคเบาหวานเป็นปัญหาทางสาธารณสุขที่สำคัญ การตรวจคัดกรองเบื้องต้นอย่างรวดเร็วสามารถลดความเสี่ยงและภาวะแทรกซ้อนได้
- **Dataset:** เลือกใช้ชุดข้อมูล **Pima Indians Diabetes Database** เนื่องจากเป็นชุดข้อมูลที่มีมาตรฐาน มีตัวแปรสำคัญที่เกี่ยวข้องกับสุขภาพชัดเจน (เช่น ระดับน้ำตาลในเลือด, ความดัน, ดัชนีมวลกาย) ซึ่งเหมาะสมสำหรับการสร้างโมเดลจำแนกประเภท (Classification)

## 2. Data Preprocessing
ขั้นตอนการเตรียมข้อมูลประกอบด้วย:
- **การจัดการค่าศูนย์ (Missing Values):** ในคอลัมน์เช่น Glucose, BloodPressure พบค่าที่เป็น 0 ซึ่งไม่สมเหตุสมผลในทางการแพทย์ จึงทำการเปลี่ยนค่าเหล่านั้นเป็น `NaN` แล้วแทนที่ด้วยค่าเฉลี่ย (Mean) ของคอลัมน์นั้นๆ
- **การปรับสเกลข้อมูล (Feature Scaling):** ใช้ `StandardScaler` เพื่อปรับข้อมูลให้อยู่ในสเกลที่เหมาะสม ทำให้โมเดล SVM ทำงานได้แม่นยำขึ้น

## 3. การสร้างโมเดล ML
- **อัลกอริทึมที่ใช้:** **Support Vector Machine (SVM)**
- **ทฤษฎี:** SVM ทำงานโดยการหาเส้นแบ่ง (Hyperplane) ที่ดีที่สุดในการแยกกลุ่มข้อมูลระหว่าง "กลุ่มที่เป็นเบาหวาน" และ "กลุ่มที่ไม่เป็นเบาหวาน" โดยพยายามเพิ่มระยะห่าง (Margin) ระหว่างข้อมูลทั้งสองกลุ่มให้กว้างที่สุดเพื่อให้ผลการทำนายมีความผิดพลาดน้อยที่สุด

## 4. การประเมินและเปรียบเทียบโมเดล
- จากการทดสอบโมเดลด้วยข้อมูลชุดทดสอบ (Test Set) พบว่าโมเดลมีความแม่นยำ (Accuracy) ที่น่าพอใจ
- (แนะนำ: เมื่อคุณรันโค้ดแล้ว ให้นำรูปภาพกราฟ Confusion Matrix ที่ได้จากแอป ไปวางในโฟลเดอร์ GitHub แล้วใช้คำสั่ง `![รูป](รูปภาพ.png)` แสดงในส่วนนี้)
