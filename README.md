# Diabetes Prediction & AI Analytics App

โปรเจ็คนี้จัดทำขึ้นเพื่อวิเคราะห์และทำนายความเสี่ยงของการเป็นโรคเบาหวาน โดยนำเทคนิค Machine Learning มาพัฒนาเป็นเว็บแอปพลิเคชันเพื่อช่วยในการคัดกรองเบื้องต้นได้อย่างรวดเร็วและแม่นยำ

## ข้อมูลผู้พัฒนา
- **ชื่อ-นามสกุล:** นายคณิศร จันทรสูตร
- **รหัสประจำตัว:** 664245019
- **หมู่เรียน:** 66/43

---

## 1. การกำหนดปัญหาและ Dataset
- **ปัญหา:** โรคเบาหวานเป็นปัญหาทางสาธารณสุขที่สำคัญ การตรวจคัดกรองเบื้องต้นอย่างรวดเร็วสามารถช่วยลดความเสี่ยงและภาวะแทรกซ้อนได้
- **Dataset:** เลือกใช้ชุดข้อมูล **Pima Indians Diabetes Database** (768 รายการ, 8 Features) ที่มีมาตรฐานและมีตัวแปรสำคัญทางสุขภาพชัดเจน เหมาะสำหรับงานจำแนกประเภท (Binary Classification)

## 2. Data Preprocessing
ขั้นตอนการเตรียมและทำความสะอาดข้อมูลประกอบด้วย:
- **การจัดการค่าศูนย์ (Missing Values):** แปลงค่า 0 ที่ผิดปกติในคอลัมน์สุขภาพ (เช่น Glucose, BMI) เป็น `NaN` แล้วแทนที่ด้วยค่าเฉลี่ย (Mean Imputation)
- **การแบ่งข้อมูล:** ทำ Train/Test Split ในสัดส่วน 80% / 20%
- **การปรับสเกลข้อมูล (Feature Scaling):** ใช้ `StandardScaler` เพื่อปรับสเกลข้อมูลให้เหมาะสมกับอัลกอริทึม

## 3. การสร้างโมเดล ML (ศึกษาทั้งหมด 5 อัลกอริทึม)
โปรเจ็คนี้ได้เปรียบเทียบโมเดลตามบทเรียนทั้งหมด 5 รูปแบบ:
1. **KNN (K-Nearest Neighbors):** จำแนกกลุ่มตามความใกล้เคียงของข้อมูลรอบข้าง
2. **Decision Tree:** วิเคราะห์เงื่อนไขแยกกลุ่มข้อมูลในรูปแบบโครงสร้างต้นไม้
3. **Logistic Regression:** โมเดลรีเกรสชันพื้นฐานสำหรับงานจำแนกประเภท
4. **SVM (Support Vector Machine):** โมเดลหลักที่ค้นหาเส้นแบ่ง (Hyperplane) ด้วยระยะ Margin ที่กว้างที่สุด
5. **Ensemble (Random Forest):** ผสานพลังต้นไม้หลายต้นเพื่อเพิ่มความเสถียรและความแม่นยำสูงสุด

## 4. การประเมินและเปรียบเทียบโมเดล
- ระบบแสดงผลตารางเปรียบเทียบค่าความแม่นยำ (Accuracy) ของทั้ง 5 โมเดล
- แสดงกราฟ **Confusion Matrix** ของโมเดลหลัก (SVM) เพื่อวิเคราะห์ผลการทำนายจริงเทียบกับสิ่งที่โมเดลทาย

## 5. Streamlit Application
- พัฒนาเว็บแอปพลิเคชันด้วย **Streamlit** ในรูปแบบ Modern Dashboard
- ผู้ใช้งานสามารถกรอกข้อมูลสุขภาพจริงและเลือกโหมดการทำนายได้ทั้งแบบ **รายโมเดล** หรือ **🚀 รันทุกโมเดลพร้อมกัน**
- ระบบแสดงผลลัพธ์พร้อมระดับความมั่นใจ (**Confidence Score %**) แบบ Real-time
